# Repo Overview

> Work in progress and not thoroughly tested.
> Expect breaking changes.

## What this is

`au-agent-guides` provides guides for working with Arsumbris.

## How to use this

Depend on `au-agent-guides` and enable the `au_agent_guide` tool to browse and read guides.

## How to extend this

Use [[write-a-guide]] to create your own guides in your repo.
The shared [[guide]] type makes them available through the same tool.
