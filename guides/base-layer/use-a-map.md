# Use a map as a reading aid

Use a map when its subject and scope fit the task.
It lets you borrow an earlier reader's organization.
Follow the sources needed for the current question before relying on the synthesis.

**Read beyond the map when needed**

A precise question may be better answered by a direct node or graph read.
A missing map does not block the work.
A misleading map should not limit the investigation.
See [[a-slice-is-the-unit-of-attention]] for expanding scope.

**Preserve useful discoveries once**

Record a discovery when it is supported and useful beyond the session.
A missing relation or stronger explanation may belong in the existing claim or map.
An unresolved question may need recording as a question.
Choose the appropriate place instead of duplicating the assertion.

**Let a read remain a read**

Reading can check existing understanding or answer a one-time question without changing the graph.
Do not add graph content merely to demonstrate productivity.
Follow the user's scope if a useful discovery needs an edit outside it.

Use [[keep-a-map-honest]] when evidence changes an interpretation.
Use [[author-a-map]] when future readers need a missing synthesis.

Name what the map helped you decide and which source supports the conclusion.
If you write back, state the new supported information.
Leave the graph as it is when nothing needs changing.
